# STUDIO 404

Playable static browser game about building a small game studio. It uses vanilla ES modules so it can be hosted directly as a Yandex Games build without a framework runtime.

## Run locally

Serve the folder over HTTP because browser ES modules are not loaded from `file://`:

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Included loop

- Create a game from data-driven genre, setting, mechanic, camera, audience and scope choices.
- Develop month by month with Proper, Work, Fast and Crunch decisions.
- Accumulate and resolve technical debt and contextual build problems.
- Fund marketing, delay or release a game with a release countdown.
- Generate reviews, ratings, sales, revenue and a sales graph from project state.
- Hire and let go of team members, upgrade the office and fund research.
- Track market temperature, competitors, achievements and studio history.
- Autosave and manual save through local storage; pause on focus loss.
- Detect Yandex Games SDK when provided by the host without requiring it locally.
- Start in 2000 with monthly market news that changes genre demand.
- License releases through fictional publishers with reputation, research and scope requirements.
- Reviews and sales respond to quality, innovation and whether the game meets the current market trend.
- Russian localization, contextual first-session tutorial and inline SVG artwork are included.
- Creation is split into three steps with a random hook, market or scope mini-game.
- Game release sales arrive over subsequent months instead of paying the full amount immediately.
- Negative cash opens a real credit offer with monthly interest and manual repayment.
- Genres, settings and platforms have separate unlock paths; recruitment candidates refresh monthly with varied skills.
- Recruitment candidates are randomly refreshed each month and show their strongest skills before hiring.
- Bad builds can launch to zero sales; credit offers appear instead of an immediate reset when cash goes negative.
- Buttons use a lightweight Web Audio feedback layer, and the office can buy equipment with real progression effects.
- Creation stays inside one modal while switching steps, with range controls for initial copies and price.
- The calendar runs automatically after development begins and pauses for important decisions; there are no manual month-advance controls.
